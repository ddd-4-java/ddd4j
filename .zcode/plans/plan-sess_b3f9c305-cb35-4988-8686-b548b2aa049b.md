## 实施方案：Lambda 类型安全查询

### 核心设计

`Query<T>` 保持聚合根泛型不变，新增 `lambdaQuery(Class<P> poClass)` 方法返回 `LambdaQuery<P>`，业务方通过 Lambda 引用 PO
字段：

```java
// 用法示例
OrderQuery query = new OrderQuery();
query.lambdaQuery(OrderPO.class)
     .eq(OrderPO::getStatus, "PAID")
     .like(OrderPO::getOrderNo, "2024")
     .ge(OrderPO::getCreateTime, startTime)
     .orderByDesc(OrderPO::getCreateTime);
Page<Order> page = query.page();
```

### Phase 1：ddd4j-core 基础设施

**1.1 创建 `SFunction<T, R>` 函数式接口**

- 文件：`ddd4j-core/.../util/SFunction.java`
- 继承 `Function<T, R>` + `Serializable`（支持 `SerializedLambda` 解析）

**1.2 创建 `LambdaKit` 工具类**

- 文件：`ddd4j-kit/.../lang/LambdaKit.java`
- `resolve(SFunction<T, ?>)` → 属性名（如 `getName` → `name`）
- 使用 `SerializedLambda` + `PropertyNamer.methodToProperty()`

**1.3 创建 `LambdaCondition` 记录**

- 文件：`ddd4j-core/.../cqrs/query/LambdaCondition.java`
- `record LambdaCondition(String property, String operator, Object value)`

**1.4 创建 `LambdaQuery<P>` 类**

- 文件：`ddd4j-core/.../cqrs/query/LambdaQuery.java`
- 链式条件方法：`eq`/`ne`/`like`/`likeLeft`/`likeRight`/`notLike`/`gt`/`ge`/`lt`/`le`/`in`/`notIn`/`isNull`/`isNotNull`/
  `between`
- 每个方法都有 `boolean condition` 重载
- 排序：`orderByAsc`/`orderByDesc`
- 存储：`List<LambdaCondition> conditions`

**1.5 创建 `LambdaUpdate<P>` 类**

- 文件：`ddd4j-core/.../cqrs/query/LambdaUpdate.java`
- SET 操作：`set`/`setSql`/`setIncrBy`/`setDecrBy`
- WHERE 条件：复用 `LambdaCondition`
- 存储：`List<String> sqlSet` + `List<LambdaCondition> conditions`

**1.6 修改 `Query.java`**

- 新增字段：`transient LambdaQuery<?> lambdaQuery` / `transient LambdaUpdate<?> lambdaUpdate`
- 新增方法：`lambdaQuery(Class<P>)` / `lambdaUpdate(Class<P>)`
- 新增辅助：`hasLambdaQuery()` / `hasLambdaUpdate()`

### Phase 2：mybatisplus 模块适配

**2.1 修复 `AbstractMybatisQuery`**

- 删除第 97-100 行死代码/语法错误
- 保留 `lambda(Class<P>)` 和 `wrapper(Class<P>)` 方法（MyBatis-Plus 原生 Wrapper 入口）

**2.2 更新 `MybatisAggregateRepository.getBaseWrapper()`**
优先级：

1. MyBatis-Plus 原生 Wrapper（`lambda()`/`wrapper()` 设置的）
2. ddd4j `LambdaQuery`（`lambdaQuery()` 设置的）→ 转换为 `QueryWrapper` 条件
3. 字段后缀自动映射（向后兼容）

### Phase 3：mybatis 模块适配

### Phase 4：JPA 模块适配

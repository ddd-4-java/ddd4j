# 1.0.x 与 2.0.x/3.0.x 模块差异说明（已移除模块清单与原因）

> 更新日期：2026-09-05
> 适用分支：`feature/1.0.x`（版本号 `1.0.x.20260630-SNAPSHOT`，JDK 1.8 基线）
> 对照分支：`feature/2.0.x`（JDK 17）/ `feature/3.0.x`（JDK 21）

本文档记录 1.0.x 分支**有意移除**的、在 2.0.x/3.0.x 中存在的模块，以及移除原因，
避免后续拓扑对比时将这些差异误判为"缺失"或"待补齐"。

版本线基线规则（既定）：

| 分支 | JDK | 三方组件线 | 典型命名空间 |
|---|---|---|---|
| 1.0.x | 1.8 | Spring 5.3 / JBoss Hibernate 5 / javax-* | javax.servlet、javax.persistence、javax.validation |
| 2.0.x | 17 | Spring 6 / Jackson 2 / jakarta-* | jakarta.servlet、jakarta.persistence |
| 3.0.x | 21 | Spring 7 / Jackson 3 / jakarta-* | jakarta.* |

---

## 一、Quarkus 系（6 个模块）——JDK 17+ 强制

Quarkus 3.x 基线为 JDK 17+，且 1.0.x BOM 不含 `quarkus-bom`（无法解析依赖版本）。
1.0.x 为 JDK 8 基线，**不做适配、永久移除**。使用方如需 Quarkus 集成请升级 2.0.x/3.0.x。

| 已移除模块 | 2.0.x/3.0.x 对应物 |
|---|---|
| `ddd4j-runtime/ddd4j-runtime-quarkus` | `ddd4j-runtime/ddd4j-runtime-quarkus` |
| `ddd4j-web/ddd4j-web-quarkus` | `ddd4j-web/ddd4j-web-quarkus` |
| `ddd4j-data/ddd4j-data-cqrs-quarkus` | `ddd4j-data/ddd4j-data-cqrs-quarkus` |
| `ddd4j-data/ddd4j-data-projection-quarkus` | `ddd4j-data/ddd4j-data-projection-quarkus` |

## 二、Panache（2 个模块）——Quarkus 专属运行时

Panache 是 Quarkus 的活动记录/仓储 ORM 层，强依赖 Quarkus 运行时与
`quarkus-hibernate-orm-panache` / `quarkus-hibernate-reactive-panache` 构件，
随 Quarkus 一并移除，原因同上。

| 已移除模块 | 2.0.x/3.0.x 对应物 |
|---|---|
| `ddd4j-data/ddd4j-data-event-store-panache` | `ddd4j-data/ddd4j-data-event-store-panache` |
| `ddd4j-data/ddd4j-data-projection-panache` | `ddd4j-data/ddd4j-data-projection-panache` |

## 三、Helidon 数据适配器（2 个模块）——三方构件字节码超纲

`ddd4j-data-cqrs-helidon` / `ddd4j-data-projection-helidon` 唯一的框架依赖是
`io.helidon.common:helidon-common-service-loader`（HelidonServiceLoader，SE 线
服务发现原语）。实测该构件在 1.0.x BOM 锁定的 Helidon **2.6.14** 下字节码
major = 55（Java 11 编译），JDK 8 的 javac 无法读取（`无法访问
io.helidon.common.serviceloader.HelidonServiceLoader`），无 JDK 8 兼容版本可回退。

注意区分：`ddd4j-web/ddd4j-web-helidon` 与 `ddd4j-runtime/ddd4j-runtime-helidon`
使用不同的构件组合（MP/JAX-RS 线），JDK 8 可编译，**仍在 1.0.x reactor 中**。

| 已移除模块 | 2.0.x/3.0.x 对应物 |
|---|---|
| `ddd4j-data/ddd4j-data-cqrs-helidon` | `ddd4j-data/ddd4j-data-cqrs-helidon` |
| `ddd4j-data/ddd4j-data-projection-helidon` | `ddd4j-data/ddd4j-data-projection-helidon` |

## 四、保留但曾疑似差异的模块（澄清）

| 模块 | 1.0.x 状态 | 说明 |
|---|---|---|
| `ddd4j-data/ddd4j-data-cqrs-micronaut` | ✅ 保留 | Micronaut 3.10.10（BOM=`io.micronaut:micronaut-bom`）支持 JDK 8。注意 Micronaut 3 的 BOM 坐标是 `io.micronaut:micronaut-bom`，`io.micronaut.platform:micronaut-platform` 是 Micronaut 4+ 才有的坐标且 3.10.10 不存在 |
| `ddd4j-data/ddd4j-data-projection-micronaut` | ✅ 保留 | 同上 |
| `ddd4j-web/ddd4j-web-helidon` | ✅ 保留 | 见第三节 |
| `ddd4j-runtime/ddd4j-runtime-helidon` | ✅ 保留 | 见第三节；`javax.inject` 由 `javax.inject:javax.inject:1` 提供（`jakarta.inject-api` 2.0.1 包名已是 `jakarta.inject`，不满足源码 import） |
| `ddd4j-data/ddd4j-data-datascope` | ✅ 保留 | javax.validation 线；`DataScopeProvider.hasPermissions` 为抽象方法（函数式接口，与 otel 测试 lambda 用法一致），默认 Bean 用 lambda 提供非空语义 |
| `ddd4j-data/ddd4j-data-jpa` | ✅ 保留 | `jakarta.persistence-api` 锁 **3.0.0**（Java 8 字节码；3.1.0 是 Java 11），JPA API 差异点：`getSingleResultOrNull`（3.1 新增）改用 `getResultList` 取首元素；`Collection.toArray(IntFunction)`（JDK 11）改 `toArray(new T[0])` |

## 五、ddd4j-samples（目录存在，但未纳入 Maven 构建）——允许轴

`ddd4j-samples/` 目录在 1.0.x 工作树中**物理存在**（2.0.x 同步带入，约 24 个示例
工程：order 领域样例 + javalin/vertx/dropwizard/helidon/micronaut/quarkus 运行时
样例 + cqrs/satoken/shiro 变体），但**根 pom 的 `<modules>` 未声明它**，因此 Maven
reactor 不会加载。

不声明的原因：
1. 示例代码是 2.0.x 运行时的（JDK 17 语法 ×121 文件、jakarta 命名空间 ×103 文件、
   quarkus/micronaut-4 运行时样例），在 1.0.x JDK 8 + javax 线下无法编译；
2. 版本线规则中"sample 差异"属允许轴——1.0.x 历史上即无 samples，示例工程按
   各版本线运行时分别提供（1.0.x 使用方参考各能力模块的测试用例）。

若后续需要 1.0.x 示例：需将 24 个示例工程逐一按本文档第三节同款方法降级
（或按 1.0.x 栈重写），并将 `ddd4j-samples` 加回根 pom `<modules>`。
git 历史保留全部样例源码（2.0.x 版：见 `feature/2.0.x` 分支同路径）。

## 六、拓扑对照结论

- 1.0.x reactor 顶层聚合根（15）：`ddd4j-{annotation,auth,bom,cache,core,data,ddd-rules,dependencies,extensions,kit,metrics,mq,parent,runtime,web}`
- 与 2.0.x/3.0.x 的其余顶层差异：
  - 2.0.x/3.0.x 独有：`ddd4j-samples`（1.0.x 按允许轴"sample 差异"不提供示例工程）
  - 2.0.x/3.0.x 独有（本文档移除项）：第一节~第三节共 10 个模块（均不在顶层，分属 runtime/web/data 聚合根）
- 除上述移除项外，三方共同模块的目录结构、类名、方法签名一致；
  差异仅允许出现在：JDK 语法、三方组件版本（Maven 依赖配置）、Jackson 大版本、
  javax/jakarta 命名空间、sample 差异。

# 1.0.x 平台模块适配说明

> 当前核对日期：2026-10-15。适用于 `feature/1.0.x`（JDK 8）。
> 2026-09-07 版本曾将下列平台模块列为已移除；该判断已被三线收敛工作替代，不能再作为当前支持范围或差异豁免依据。历史版本可从 Git 历史查阅。

1.0.x 与 2.0.x、3.0.x 保持相同的产品能力与业务契约，但各线必须使用自身 JDK 可用的框架版本、依赖、命名空间和 Java 语法。当前任务和验收状态见 [三线收敛计划](superpowers/plans/2026-10-10-three-line-product-convergence.md)；源码、目录和测试仍须按该计划核验，模块存在不等于整线验收通过。

| 平台 | 1.0.x 的适配方式 | 当前纳入的模块 |
| --- | --- | --- |
| Quarkus | 模块自身使用 Quarkus `1.13.7.Final` BOM，保留 JDK 8 / `javax.*` 入口；不得直接复制高两线 Quarkus 3 的 API 或依赖。 | `ddd4j-runtime-quarkus`、`ddd4j-web-quarkus`、`ddd4j-data-cqrs-quarkus`、`ddd4j-data-projection-quarkus` |
| Panache | 使用本线 Quarkus 1 的 Panache API。 | `ddd4j-data-event-store-panache`、`ddd4j-data-projection-panache` |
| Helidon | 使用 Helidon `1.4.19` 与 JDK 8 可用的 `javax.*` API；数据适配器使用同线 `helidon-common-service-loader`。 | `ddd4j-runtime-helidon`、`ddd4j-web-helidon`、`ddd4j-data-cqrs-helidon`、`ddd4j-data-projection-helidon` |
| Micronaut | 使用 Micronaut `3.10.10` 与本线 BOM；保留 Micronaut 3 的过滤器和上下文入口。 | `ddd4j-data-cqrs-micronaut`、`ddd4j-data-projection-micronaut` 及对应运行时、Web 适配 |

`ddd4j-samples/pom.xml` 当前还纳入 Quarkus 普通、CQRS、Sa-Token、Shiro 四个样例，Helidon 普通与 CQRS 两个样例，以及 Micronaut 普通与 CQRS 两个样例。旧版“这些样例不进入 1.0.x”的说法已经失效。

另外，`ddd4j-data-datascope` 保留 `DataScopeProvider.hasPermissions` 函数式接口，默认实现仅允许非空数据；`ddd4j-data-jpa` 在本线 BOM 中仍管理 `jakarta.persistence-api:3.0.0`。这些是本线现有兼容适配，不构成删除共同业务行为的理由。

各平台的源码入口、依赖和字节码可随 JDK 版本变化；共同业务行为须由三线场景矩阵和各自目标测试证明。特别是 Quarkus 1 的 RESTEasy Filter、Quarkus 3 的 REST Filter，以及 Helidon 1 与高线的容器 API，应按各线真实入口比较请求、响应、上下文清理和异常行为。现行差异不得因为旧版删除清单而自动获得豁免。

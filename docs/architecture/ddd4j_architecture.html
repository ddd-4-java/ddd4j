Ddd4j 最终架构定位

ddd4j 是一个框架无关的 DDD/CQRS/ES 通用基础层，目标是为 Spring Boot、Quarkus、Javalin 三种容器框架提供 同一套纯净领域模型契约，站在 fuinorg 系列（ddd-4-java + cqrs-4-java + esc-api）之上。

ddd4j 三大核心 SPI

SPI 职责 实现数量
DomainEventPublisher 进程内领域事件发布 3（Spring / CDI / Guice）
MQBrokerAdapter 跨进程消息发布/订阅 12（Kafka / RabbitMQ / RocketMQ / ActiveMQ / RedisStream / MQTT / MicaMQTT / Pulsar / NATS / Disruptor / ONS ...）
Repository 数据访问抽象 多 ORM（MyBatis-Plus / Hibernate Panache / JDBI）

与 fuinorg 基础库的关系

  • 继承 ddd-4-java 的 AbstractAggregateRoot → ddd4j DddAggregateRoot（增加 createTime/updateTime 审计字段）
  • 复用 ddd-4-java 的 AbstractDomainEvent → ddd4j DddDomainEvent
  • 封装 cqrs-4-java 的 EventStoreRepository → ddd4j DddEventStoreRepository（乐观锁冲突重试 3 次）
  • 扩展 cqrs-4-java 的 Command/View 抽象到 ddd4j 三框架运行时绑定层
  • 依赖 esc-api 作为 EventStore 抽象接口（EventStoreDB / KurrentDB）

ddd4j 应补充的 CQRS/ES 能力（P0/P1 分级）

优先级 能力 实施建议
P0 Command / AggregateCommand 接口 抽取到 ddd4j-core 作为契约
P0 CommandExecutor SPI 三框架各自实现
P0 CommandHandler 注解 + 自动注册 兼容 Spring @Component / CDI Bean
P0 MultiCommandExecutor / Result<T> 复用 fuinorg 实现
P1 View / JpaView 接口 抽取到 ddd4j-core
P1 ViewManager 抽象 ddd4j-runtime-spring / ddd4j-runtime-quarkus 各自实现
P1 ProjectionPosition 投影位置持久化 抽取为公共 SPI
P1 @CreateEvent / @UpdateEvent / @DeleteEvent 注解 复用 fuinorg

ddd4j 核心竞争力

  • 框架无关纯净契约：core 模块 contract/context/ddd 包零框架 import
  • 13 个 MQ Broker/本地实现统一抽象：MQBrokerAdapter SPI 切换消息中间件零业务代码改动
  • ArchUnit 编译期守护：CleanDDDLayerRules / ColaDDDLayerRules 注解驱动
  • 双轨 DDD 模型：BaseEntity（快速）/ DddAggregateRoot（纯净 ES）
  • 站在巨人肩膀上：直接复用 fuinorg ddd-4-java + cqrs-4-java + esc-api
